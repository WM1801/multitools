### Многофункциональное устройство на базе платы esp32c3_supermini 

### Подключенные устройства: 
- Пин 8 - светодиод  

### Подсказки 
- Сборка 
```
west build -b esp32c3_supermini --pristine
```
- Прошивка
```
west flash 
```
- Открыть монитор (Последовательный порт к чипу, на время прошивки закрывать)
```
west espressif monitor
```

- Открыть в текущем docker вторую консоль 
```
 docker exec -it df3449c1ca4b /bin/bash
```
